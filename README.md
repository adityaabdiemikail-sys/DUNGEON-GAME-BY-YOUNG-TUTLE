# 🏰 TUTLE'S RPG

A small RPG game made by Young Tutle while learning Python.

> 🎮 Current Version: V1.1

## 📖 About

TUTLE'S RPG is a text-based RPG made in Python.

I'm building this project while learning programming by myself.
The goal is to keep improving the game through multiple versions.

## ⚔️ Current Features

- ⚔️ Combat system
- 💥 Critical hits
- 👹 Enemy critical hits
- 🛡️ Armor and defense
- ❤️ Health system
- 🧪 Healing
- 🎒 Inventory
- 💰 Gold
- ⚔️ Weapons
- 👾 Multiple enemies
- 🎁 Enemy loot
- ⏱️ Combat timer
- 🎲 Random events
