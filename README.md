# 🎮 Dungeon Escape

My first real Python game!

Dungeon Escape is a text-based RPG that I built from scratch while learning Python.

## 🕹️ Features

- ⚔️ Combat system
- 👾 Multiple enemies
- 🎒 Inventory system
- 🛡️ Armor system
- 🧪 Potion system
- 🏪 Shop system
- 💰 Gold system
- ⭐ XP and leveling system
- 📜 Quest system
- 🎲 Random enemy encounters
- 🎁 Enemy loot drops
- 📊 Player statistics

## 🐍 Built With

- Python
- Python `random`
- Python `copy`

## ▶️ How to Run

Make sure Python 3 is installed.

Run:

```bash
python3 portofolio_dungeon_escape.py
